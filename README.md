## 双ISP住宅IP到底是什么意思

双ISP指一个IP在数据库的两个字段——所属机构和ASN用途类型——都显示为住宅宽带运营商。比只有一个字段是住宅的“单ISP住宅IP”信号更强，能通过更严格的风控检查。

对比一下就明白了。普通东京VPS的IP登记在Vultr、DigitalOcean这类托管商的ASN下，TikTok、Netflix、DMM或者支付网关一查WHOIS和地理数据库，看到的是“数据中心”。结果就是：新开的东京VPS看不了Netflix日本，TikTok账号几天内被限流，Scamalytics风控分居高不下。双ISP住宅IP的IP段登记在真实服务家庭用户的运营商名下——丽萨主机日本线用的是IIJ（Internet Initiative Japan，日本最大的骨干运营商之一），越南线用的是西贡邮电（SPT）的家宽段。平台查询时，它看起来就是一个普通的本地家庭用户。

拿到机器后，可以用Scamalytics、ipinfo.io这类工具验证：双ISP住宅IP的fraud score通常很低，用途类型显示residential或isp。
